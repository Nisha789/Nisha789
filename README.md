## 💫 About Me

I'm a **Data & AI Engineer at TCS** with **3+ years** of experience designing scalable data platforms on **Microsoft Azure**. I specialise in building high-performance ETL/ELT pipelines — and increasingly, intelligent systems that go beyond traditional data engineering.

- 🏗️ **Data Engineering** — Design and optimise multi-terabyte pipelines using **Databricks, PySpark, Delta Lake, and Azure Data Factory**, delivering reliable, analytics-ready data at scale.
- 🤖 **Agentic AI** — Built an **Agentic Newsroom**: a multi-agent workflow where AI agents autonomously research, write, and refine content in real time.
- 🔬 **AI/ML PoCs** — Contributed to proof-of-concept initiatives in **Gen AI and Machine Learning**, focused on scalable, production-ready approaches.
- 🤝 **Cross-functional Collaboration** — Partner with solution architects, BI developers, and frontend teams to deliver end-to-end data solutions in agile environments.
- 📈 **Optimisation** — Automated data validation workflows, reducing manual intervention significantly while achieving high pipeline reliability for business-critical reporting.
